Longshot-Unterstützung

Beginnen Sie mit der verbundenen Registerkarte

Öffnen Sie Ihr autorisiertes Ziel, melden Sie sich an, starten Sie Longshot über diese Registerkarte und stellen Sie eine Verbindung her. Nutzen Sie Informationen und Erste Schritte für den aktuellen Release-Workflow. Eine öffentliche HTTP 200-Seite beweist keine Authentifizierung; configure a protected validator.

Einheimische Brücke

Im Leitfaden „Browser Bridge Information“ werden der separate Node/Python-Adapter, der genaue Ursprung der Erweiterung, Proxy-/Kontrollports, Token und HTTPS-CA-Vertrauen erläutert. Verwenden Sie echte Ziel-URLs. Es ist kein Eintrag in „bridge.invalid“ oder „hosts-file“ erforderlich. Cookie-Überschreibungen und Antwortsynchronisierung sind unabhängig voneinander. Ein rotierender veralteter Cookie kann mit einer Scannersonde verwechselt werden. Deaktivieren Sie die automatische Beibehaltung von Änderungen, wenn das JAR von Firefox/Chrome autorisierend bleiben und absichtliche Testfelder explizit schützen muss.

Unterschiede zwischen Chrome und Firefox

Chrome verwendet Manifest V3 und erfordert, dass die sichtbare Workbench geöffnet bleibt. Der aktuelle Chrome-Build deaktiviert explizit die aufgeführten Funktionen für Firefox-Blockierung, Live-DOM, Container und Hintergrunderfassung. Firefox behält seine unterstützten Plattformfunktionen. Lesen Sie den im Produkt enthaltenen Leistungshinweis, anstatt von einer identischen Abdeckung auszugehen.

Berichte und Datenentfernung

Überprüfen Sie die erfassten Anwendungsdaten, bevor Sie sie exportieren oder teilen. Löschen Sie die aktive Bewertung in den Einstellungen; Löschen Sie optional exportierte/native Dateien dort, wo sie gespeichert wurden. Auf der Datenschutzseite werden Speicher und Integrationen erläutert.

Ein Problem melden

Öffnen Sie ein Problem der öffentlichen Unterstützung, oder verwenden Sie den Entwickler-/Herausgeberkontakt in der Browser-Store-Liste, sobald die Erweiterung aufgeführt ist. GitHub-Probleme sind öffentlich; Zum Einreichen ist ein GitHub-Konto erforderlich. Fügen Sie Browser-/Erweiterungsversionen, die Aktion und einen redigierten Fehler hinzu. Senden Sie keine Sitzungscookies, Anmeldeinformationen, privaten Ziele, privaten CA-Schlüssel oder vertraulichen Rohberichte. Diese Website enthält kein Kontaktformular und sammelt keine Supportbeiträge.

Marktplatzstatus

Browser-Paketierung und automatisierte Prüfungen stellen keine Marktfreigabe dar. Store-Einträge, Vertrieb und Signierung werden über das Konto des Herausgebers verwaltet.
