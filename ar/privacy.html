الخصوصية ومعالجة البيانات

اسم عرض الناشر: Longshot Security. ينطبق على إصدارات Firefox وChrome من Longshot. Longshot عبارة عن منصة عمل لتقييم أمان الويب المعتمد. ولا يحتوي على تحليلات المطورين أو الإعلانات أو خدمة تحميل الفحص التي يديرها المطور. لا يتطلب الامتداد حساب مطور.

البيانات المستخدمة

بعد توصيل هدف، تقوم Longshot بمعالجة عنوانه ومحتوى الصفحة ونقاط النهاية المكتشفة وبيانات تعريف HTTP وهيئات طلب/استجابة الماسح الضوئي المدعومة والنتائج وملاحظات المراجعة. توفر علامة تبويب المتصفح المتصلة جلسة التقييم. يمكن لـ Browser Bridge أيضًا قراءة قيم ملفات تعريف الارتباط القابلة للتطبيق، بما في ذلك ملفات تعريف الارتباط HttpOnly، وقيم المصادقة/الرأس المحددة بشكل واضح من مخزن ملفات تعريف الارتباط لعلامة التبويب المقترنة. تعمل هذه القيم على تمكين الطلبات المصادق عليها بواسطة أدواتك المحلية.

يتم تخزين أدلة التقييم وملفات التعريف المستهدفة والتفضيلات محليًا في وحدة تخزين الامتداد/IndexedDB. يمكن أن تحتوي الاستجابات الاختيارية المحتفظ بها على معلومات التطبيق على الرغم من تنقيح بذل أفضل جهد. تتم كتابة التقارير/ملفات الجلسة المصدرة الاختيارية أو تنزيلها في المكان الذي تختاره ولا يتم تشفيرها بواسطة Longshot. إن جرة ملفات تعريف الارتباط للمتصفح المحلي منفصلة عن تصدير التقييم.

أين تذهب البيانات

  • يرسل فحص المتصفح طلبات الاختبار المحددة إلى الهدف المتصل ضمن النطاق والحدود التي تم تكوينها. يؤدي فتح الصفحات المستهدفة المباشرة إلى تحميل مواردها العادية من خلال المتصفح.
  • جسر المتصفح اختياري. يقوم الاقتران بشكل صريح بتوصيل محول أصلي محلي تم تشغيله بشكل منفصل. يتم إرسال ملفات تعريف الارتباط القابلة للتطبيق والرؤوس التي تم اختيارها إلى مساعد الاسترجاع المصادق عليه لتشكيل طلبات الأداة الصادرة. يتم تمكين مزامنة ملفات تعريف الارتباط للاستجابة بشكل افتراضي ويمكن تعطيلها بشكل مستقل. ثم تتبع حركة المرور المستهدفة المسار المباشر/المنبع/SOCKS الذي تم تكوينه للمحول. يمكن للأدوات الخارجية أن تحتفظ بتاريخها الخاص؛ فحص إعداداتها قبل الاستخدام.
  • تعتبر واجهة برمجة تطبيقات الوكيل/المراسلة الأصلية اختيارية وتتطلب تثبيتًا واتصالًا منفصلين للمضيف الأصلي. فهو يسمح للعملاء المحليين المعتمدين، بما في ذلك وكلاؤك، بتشغيل منصة العمل وتلقي النتائج واستخدام ميزات ملف الجلسة/القالب الأصلي التي تم تكوينها بشكل صريح. يمكن لأتمتة واجهة المستخدم الكاملة تشغيل مربع حوار الموافقة. تعامل مع الوصول إلى تلك الواجهات المحلية على أنه امتياز.
  • يعد OAST اختياريًا ويتصل بالمزود الذي قمت بتكوينه. يمكن أن يؤدي التسجيل/الاقتراع وارتباط رد الاتصال والتفاعلات المحفزة للهدف إلى الكشف عن بيانات تعريف الاتصال/IP والتحقق من ذلك الموفر. المزود لديه سياسته الخاصة. لا يتم إرسال مجال رد الاتصال أو رمز الموفر إلى خدمة مطور Longshot.
  • يعد تحديث قوائم GitHub إجراءً صريحًا لجلب مصادر الحمولة/النماذج العامة الثابتة مع حذف ملفات تعريف الارتباط. لا يتم إرسال عناوين URL المستهدفة ونصوص الاستجابة وملفات تعريف الارتباط والحزم المخصصة التي تم تحميلها إلى GitHub من خلال هذا الإجراء.
  • البحث عن CVE عبر الإنترنت هو إجراء واضح للاستعلام عن NVD/OSV بإحداثيات المنتج/الحزمة المدعومة. ولا يرسل عناوين URL أو الصفحات أو ملفات تعريف الارتباط للجلسة المستهدفة؛ يتلقى المزود إحداثيات البرنامج وبيانات تعريف الاتصال العادية.
  • يتم تصدير التقرير/الجلسة/الموضوع فقط من خلال المستخدم المقابل أو إجراء التشغيل الآلي المصادق عليه. إن مشاركة هذه الملفات هو قرارك.

يتم استخدام/نقل بيانات المتصفح فقط لميزات تقييم الأمان التي تم الكشف عنها، بموجب سياسة بيانات مستخدم سوق Chrome الإلكتروني بما في ذلك متطلبات الاستخدام المحدود. لا يوجد بيع لبيانات التقييم أو استخدامها للإعلان أو الائتمان أو التوصيف غير ذي الصلة أو تدريب نموذج المطورين. لا تستدعي ترجمات واجهة المستخدم المجمعة مترجمًا عبر الإنترنت في وقت التشغيل. يتم تكوين عملاء الطراز المحلي/MCP الاختياريين بشكل مستقل ويتمتعون بمعالجة البيانات الخاصة بهم.

التحكم والاحتفاظ

استخدم الإعدادات → مسح بيانات المسح لمسح دليل المسح الخاص بالملف الشخصي النشط. إدارة الملفات الشخصية والمواد المستوردة من خلال طاولة العمل؛ تؤدي إزالة الامتداد إلى إزالة مساحة تخزين الامتدادات المملوكة للمتصفح. احذف التقارير المُصدَّرة وأدلة التدقيق الأصلية ومفاتيح CA وملفات الجلسة الاختيارية بشكل منفصل حيث تم حفظها. لا توجد فترة احتفاظ للمطورين لأن Longshot لا تقوم بتشغيل الواجهة الخلفية لتحميل التقييم.

يعد تجاوز ملف تعريف الارتباط لطلب الوكيل ومزامنة ملف تعريف الارتباط للاستجابة ومصادر الرأس عناصر تحكم منفصلة. إن تعطيل أحد هذه العناصر ليس وعدًا بتوقف عملية تكامل أخرى. أوقف/افصل المساعد المحلي ذي الصلة وقم بإزالة تسجيله الأصلي إذا لم تعد تريده متاحًا. يمكن أن يؤدي إلغاء أذونات المتصفح إلى تعطيل الميزات التابعة.

يتم تشغيل عمليات فحص Chrome/الاقتران الأصلي بينما تظل طاولة العمل المرئية للمستخدم مفتوحة. إغلاقه ينهي عمل المحرك المباشر. الأدلة المستمرة لا تزال قائمة. يستخدم Firefox صفحة الخلفية الثابتة المعلنة. لا يسمح إصدار Chrome بعملية التصفح المتخفي في هذا الإصدار؛ يتم استخدام سياقات Firefox الخاصة/الحاوية فقط عند تحديدها ويسمح لها الوصول إلى المتصفح.

الأذونات

الوصول إلى المضيف وعلامات التبويب ودعم إدخال البرنامج النصي لتوصيل هدف معتمد عشوائيًا وفحص/اختبار صفحاته. يراقب webRequest بيانات تعريف HTTP الخاصة بعلامة التبويب المحددة؛ ولا يتم استخدامه لتحليلات سجل تصفح المطورين. تدعم ملفات تعريف الارتباط ميزة الجلسة الأصلية المقترنة. يحتفظ التخزين بالأدلة/التفضيلات المحلية. تقرير الإخطارات الاهتمام التقييم. تعد المراسلة الأصلية اختيارية لمضيف Agent API المثبت بشكل منفصل. يدعم إذن الحظر الاختياري الخاص بـ Firefox حراس الاعتراض الصريح/live-DOM؛ لم يتم طلبه بواسطة Chrome.

يستخدم المساعدون المحليون عمليات التحقق من المصادقة/الأصل ومستمعي الاسترجاع، لكن يمكنهم معالجة أسرار الجلسة في الذاكرة. لا تضمن مشاركة ملفات تعريف الارتباط توجيه TLS/IP المطابق للمتصفح أو قبول WAF أو البرامج المستوردة الآمنة تلقائيًا. قم بمراجعة عمليات التكامل والحمولات/القوالب المؤلفة والأهداف المقصودة قبل تمكينها.

هذا الموقع

لا يحتوي موقع Longshot الثابت هذا على نصوص تحليلية أو إعلانات خارجية أو نموذج اتصال أو خدمة تحميل التقييم. تستضيفه صفحات GitHub وتسجل عناوين IP الخاصة بالزائرين لأغراض أمنية. انظر جمع بيانات صفحات جيثب و بيان خصوصية جيثب. تتمتع صفحات إصدار متجر المتصفح وGitHub بمعالجة البيانات الخاصة بها.
