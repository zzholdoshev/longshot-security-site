Longshot Securityஆவணப்படுத்தல்தனியுரிமைஆதரவு

லாங்ஷாட் தனியுரிமை மற்றும் தரவு கையாளுதல்

வெளியீட்டாளர் காட்சி பெயர்: லாங்ஷாட் பாதுகாப்பு. லாங்ஷாட்டின் Firefox மற்றும் Chrome பதிப்புகளுக்குப் பொருந்தும். லாங்ஷாட் என்பது அங்கீகரிக்கப்பட்ட வலைப் பாதுகாப்பு மதிப்பீட்டிற்கான ஒரு பணியிடமாகும். இதில் டெவலப்பர் பகுப்பாய்வு, விளம்பரம் அல்லது டெவலப்பர் இயக்கும் ஸ்கேன் பதிவேற்ற சேவை இல்லை. நீட்டிப்புக்கு டெவலப்பர் கணக்கு தேவையில்லை.

பயன்படுத்தப்பட்ட தரவு

நீங்கள் ஒரு இலக்கை இணைத்த பிறகு, லாங்ஷாட் அதன் முகவரி, பக்க உள்ளடக்கம், கண்டுபிடிக்கப்பட்ட இறுதிப்புள்ளிகள், HTTP மெட்டாடேட்டா, ஆதரிக்கப்படும் ஸ்கேனர் கோரிக்கை/பதிலளிப்பு அமைப்புகள், கண்டுபிடிப்புகள் மற்றும் மதிப்பாய்வு குறிப்புகளை செயலாக்குகிறது. இணைக்கப்பட்ட உலாவி தாவல் மதிப்பீட்டின் அமர்வை வழங்குகிறது. Browser Bridge ஆனது Httpமட்டும் குக்கீகள் உட்பட பொருந்தக்கூடிய குக்கீ மதிப்புகளையும், இணைக்கப்பட்ட தாவலின் குக்கீ ஸ்டோரில் இருந்து வெளிப்படையாகத் தேர்ந்தெடுக்கப்பட்ட கவனிக்கப்பட்ட அங்கீகாரம்/தலைப்பு மதிப்புகளையும் படிக்க முடியும். இந்த மதிப்புகள் உங்கள் உள்ளூர் கருவிகள் மூலம் அங்கீகரிக்கப்பட்ட கோரிக்கைகளை செயல்படுத்துகின்றன.

மதிப்பீட்டுச் சான்றுகள், இலக்கு சுயவிவரங்கள் மற்றும் விருப்பத்தேர்வுகள் நீட்டிப்பு சேமிப்பு/இன்டெக்ஸ் டிபியில் உள்ளூரில் சேமிக்கப்படும். விருப்பத் தக்க பதில்கள் சிறந்த முயற்சியைக் குறைத்தாலும் பயன்பாட்டுத் தகவலைக் கொண்டிருக்கலாம். விருப்ப ஏற்றுமதி செய்யப்பட்ட அறிக்கைகள்/அமர்வு கோப்புகள் நீங்கள் தேர்வு செய்யும் இடத்தில் எழுதப்பட்ட அல்லது பதிவிறக்கம் செய்யப்படும் மற்றும் Longshot மூலம் குறியாக்கம் செய்யப்படவில்லை. உள்ளூர் உலாவி குக்கீ ஜாடி ஒரு மதிப்பீட்டு ஏற்றுமதியிலிருந்து வேறுபட்டது.

  • ஏஜென்ட் ஏபிஐ/நேட்டிவ் மெசேஜிங் விருப்பமானது மற்றும் தனி நேட்டிவ் ஹோஸ்ட் நிறுவல் மற்றும் இணைப்பு தேவைப்படுகிறது. இது உங்கள் முகவர்கள் உட்பட அங்கீகரிக்கப்பட்ட உள்ளூர் கிளையண்டுகளை பணியிடத்தை இயக்கவும், முடிவுகளைப் பெறவும் மற்றும் வெளிப்படையாக உள்ளமைக்கப்பட்ட அமர்வு-கோப்பு/நேட்டிவ்-டெம்ப்ளேட் அம்சங்களைப் பயன்படுத்தவும் அனுமதிக்கிறது. முழு UI ஆட்டோமேஷன் ஒப்புதல் உரையாடலை இயக்க முடியும். அந்த உள்ளூர் இடைமுகங்களுக்கான அணுகலை சிறப்புரிமையாகக் கருதுங்கள்.

  • அறிக்கை/அமர்வு/தீம் ஏற்றுமதிகள் தொடர்புடைய பயனர் அல்லது அங்கீகரிக்கப்பட்ட ஆட்டோமேஷன் செயல் மூலம் மட்டுமே நிகழும். அந்தக் கோப்புகளைப் பகிர்வது உங்கள் முடிவு.

Chrome Web Store பயனர் தரவுக் கொள்கையின் கீழ், வரையறுக்கப்பட்ட பயன்பாட்டுத் தேவைகள் உட்பட, வெளிப்படுத்தப்பட்ட பாதுகாப்பு மதிப்பீட்டு அம்சங்களுக்காக மட்டுமே உலாவி தரவு பயன்படுத்தப்படுகிறது/பரிமாற்றம் செய்யப்படுகிறது. மதிப்பீடு தரவு விற்பனை அல்லது விளம்பரம், கடன், தொடர்பில்லாத விவரக்குறிப்பு அல்லது டெவலப்பர் மாதிரி பயிற்சிக்கான பயன்பாடு இல்லை. தொகுக்கப்பட்ட UI மொழிபெயர்ப்புகள் இயக்க நேரத்தில் ஆன்லைன் மொழிபெயர்ப்பாளரை அழைக்காது. விருப்ப லோக்கல்-மாடல்/எம்சிபி கிளையண்டுகள் சுயாதீனமாக கட்டமைக்கப்படுகின்றன மற்றும் அவற்றின் சொந்த தரவு கையாளுதலைக் கொண்டுள்ளன.

கட்டுப்பாடு மற்றும் வைத்திருத்தல்

செயலில் உள்ள சுயவிவரத்தின் ஸ்கேன் ஆதாரத்தை அழிக்க, அமைப்புகள் → ஸ்கேன் தரவை அழிக்கவும். பணியிடத்தின் மூலம் சுயவிவரங்கள் மற்றும் இறக்குமதி செய்யப்பட்ட பொருட்களை நிர்வகிக்கவும்; நீட்டிப்பை அகற்றுவது அதன் உலாவிக்குச் சொந்தமான நீட்டிப்பு சேமிப்பிடத்தை நீக்குகிறது. ஏற்றுமதி செய்யப்பட்ட அறிக்கைகள், நேட்டிவ் ஆடிட் டைரக்டரிகள், CA கீகள் மற்றும் விருப்ப அமர்வு கோப்புகள் சேமிக்கப்பட்ட இடங்களை தனித்தனியாக நீக்கவும். லாங்ஷாட் மதிப்பீட்டைப் பதிவேற்ற பின்தளத்தில் செயல்படாததால் டெவலப்பர் தக்கவைப்பு காலம் இல்லை.

ப்ராக்ஸி கோரிக்கை-குக்கீ மேலெழுதல், பதில்-குக்கீ ஒத்திசைவு மற்றும் தலைப்பு ஆதாரம் ஆகியவை தனித்தனியான கட்டுப்பாடுகள். ஒன்றை முடக்குவது மற்றொரு ஒருங்கிணைப்பு நிறுத்தப்படும் என்ற வாக்குறுதி அல்ல. தொடர்புடைய உள்ளூர் உதவியாளரை நிறுத்தவும்/துண்டிக்கவும், அது இனி கிடைக்காவிட்டால், அதன் சொந்தப் பதிவை அகற்றவும். உலாவி அனுமதிகளைத் திரும்பப் பெறுவது சார்ந்த அம்சங்களை முடக்கலாம்.

பயனர் காணக்கூடிய ஒர்க்பெஞ்ச் திறந்திருக்கும் போது Chrome ஸ்கேன்/நேட்டிவ் இணைத்தல் இயங்கும். அதை மூடுவது நேரடி இயந்திர வேலை முடிவடைகிறது; நீடித்த சான்றுகள் உள்ளன. பயர்பாக்ஸ் அதன் அறிவிக்கப்பட்ட நிலையான பின்புலப் பக்கத்தைப் பயன்படுத்துகிறது. இந்த வெளியீட்டில் மறைநிலை செயல்பாட்டை Chrome பதிப்பு அனுமதிக்காது; பயர்பாக்ஸ் பிரைவேட்/கன்டெய்னர் சூழல்கள் தேர்ந்தெடுக்கப்பட்டால் மட்டுமே பயன்படுத்தப்படும் மற்றும் உலாவி அணுகல் அவற்றை அனுமதிக்கும்.

அனுமதிகள்

ஹோஸ்ட் அணுகல், தாவல்கள் மற்றும் ஸ்கிரிப்ட் உட்செலுத்துதல் ஆதரவு தன்னிச்சையான அங்கீகரிக்கப்பட்ட இலக்கை இணைக்கிறது மற்றும் அதன் பக்கங்களை ஆய்வு/சோதனை செய்கிறது. webRequest ஸ்கோப் செய்யப்பட்ட தாவலின் HTTP மெட்டாடேட்டாவை கவனிக்கிறது; டெவலப்பர் உலாவல்-வரலாறு பகுப்பாய்வுகளுக்கு இது பயன்படுத்தப்படவில்லை. குக்கீகள் இணைக்கப்பட்ட நேட்டிவ் அமர்வு அம்சத்தை ஆதரிக்கின்றன. சேமிப்பகம் உள்ளூர் சான்றுகள்/விருப்பங்களை வைத்திருக்கிறது. அறிவிப்புகள் அறிக்கை மதிப்பீடு கவனம். தனித்தனியாக நிறுவப்பட்ட ஏஜென்ட் ஏபிஐ ஹோஸ்டுக்கு நேட்டிவ் மெசேஜிங் விருப்பமானது. பயர்பாக்ஸின் விருப்பத் தடுப்பு அனுமதி அதன் வெளிப்படையான இடைமறிப்பு/நேரடி-DOM காவலர்களை ஆதரிக்கிறது; இது Chrome ஆல் கோரப்படவில்லை.

உள்ளூர் உதவியாளர்கள் அங்கீகரிப்பு/மூலம் காசோலைகள் மற்றும் லூப்பேக் கேட்போர்களைப் பயன்படுத்துகின்றனர், ஆனால் நினைவகத்தில் அமர்வு ரகசியங்களைச் செயல்படுத்த முடியும். குக்கீ பகிர்வு உலாவிக்கு ஒரே மாதிரியான TLS/IP ரூட்டிங், WAF ஏற்றுக்கொள்ளுதல் அல்லது தானாகவே பாதுகாப்பான இறக்குமதி செய்யப்பட்ட நிரல்களுக்கு உத்தரவாதம் அளிக்காது. ஒருங்கிணைப்புகள், எழுதப்பட்ட பேலோடுகள்/டெம்ப்ளேட்கள் மற்றும் அவற்றை இயக்கும் முன் நோக்கப்பட்ட இலக்குகளை மதிப்பாய்வு செய்யவும்.

இந்த இணையதளம்

இந்த நிலையான லாங்ஷாட் இணையதளத்தில் பகுப்பாய்வு ஸ்கிரிப்டுகள், மூன்றாம் தரப்பு விளம்பரம், தொடர்பு படிவம் அல்லது மதிப்பீட்டுப் பதிவேற்றச் சேவை இல்லை. GitHub பக்கங்கள் அதை ஹோஸ்ட் செய்து, பாதுகாப்பு நோக்கங்களுக்காக பார்வையாளர்களின் IP முகவரிகளை பதிவு செய்கிறது. பார்க்கவும் GitHub பக்கங்களின் தரவு சேகரிப்பு மற்றும் தி GitHub தனியுரிமை அறிக்கை. பிரவுசர்-ஸ்டோர் மற்றும் கிட்ஹப் வெளியீட்டுப் பக்கங்கள் அவற்றின் சொந்த தரவு கையாளுதலைக் கொண்டுள்ளன.

வெளியீட்டாளர் தொடர்பு

வெளியீட்டாளர் காட்சி பெயர்: லாங்ஷாட் பாதுகாப்பு. பார்க்கவும் ஆதரவு அமைப்பு உதவி மற்றும் பயன்படுத்த பொது ஆதரவு பிரச்சினை கண்காணிப்பாளர் திருத்தப்பட்ட கேள்விகளுக்கு அல்லது கிடைத்தவுடன் தொடர்புடைய உலாவி ஸ்டோர் பட்டியலில் உள்ள வெளியீட்டாளர் தொடர்பு. பிரச்சினைகள் பொது; நற்சான்றிதழ்கள், தனிப்பட்ட இலக்குகள் அல்லது மதிப்பீட்டுச் சான்றுகளை சேர்க்க வேண்டாம். இந்தக் காட்சிப் பெயரால் ஸ்டோர் ஒப்புதல் அல்லது பதிவு செய்யப்பட்ட நிறுவன நிலை எதுவும் கோரப்படவில்லை.

லாங்ஷாட் பாதுகாப்பு · அங்கீகரிக்கப்பட்ட மதிப்பீடுகள் மட்டுமே · பகுப்பாய்வு அல்லது விளம்பர டிராக்கர்கள் இல்லை.

மொழிபெயர்ப்புகள் இயந்திரத்தால் உருவாக்கப்பட்டவை. ஆங்கிலப் பதிப்புதான் குறிப்பு.
