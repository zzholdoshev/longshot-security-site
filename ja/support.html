ロングショットのサポート

接続されたタブから始める

承認されたターゲットを開いてサインインし、そのタブから Longshot を起動して接続します。現在のリリースのワークフローについては、「情報」と「はじめに」を使用してください。パブリック HTTP 200 ページは認証を証明しません。保護されたバリデーターを構成します。

ネイティブブリッジ

ブラウザ ブリッジ情報ガイドでは、個別のノード/Python アダプタ、正確な拡張子の起点、プロキシ/制御ポート、トークン、および HTTPS CA トラストについて説明しています。実際のターゲット URL を使用します。 Bridge.invalid または hosts-file エントリは必要ありません。 Cookie のオーバーライドと応答の同期は独立しています。回転する古いクッキーはスキャナープローブと間違われる可能性があります。 Firefox/Chrome の jar が権限を維持し、意図的なテスト フィールドを明示的に保護する必要がある場合は、自動変更保存を無効にします。

Chrome と Firefox の違い

Chrome は Manifest V3 を使用しており、表示されているワークベンチを開いたままにしておく必要があります。現在の Chrome ビルドでは、リストされている Firefox のみのブロック、ライブ DOM、コンテナ、およびバックグラウンド キャプチャ機能が明示的に無効になっています。 Firefox は、サポートされているプラ​​ットフォーム機能を維持します。同一の対象範囲を仮定するのではなく、製品内の機能に関する注記をお読みください。

レポートとデータ削除

エクスポートまたは共有する前に、キャプチャされたアプリケーション データを確認してください。設定でアクティブな評価をクリアします。オプションのエクスポート/ネイティブ ファイルが保存されている場所を削除します。プライバシー ページでは、ストレージと統合について説明しています。

問題を報告する

開く 公的支援の問題、または、拡張機能がリストに表示されたら、ブラウザー ストアのリストにある開発者/発行者の連絡先を使用します。 GitHub の問題は公開されています。送信するには GitHub アカウントが必要です。ブラウザ/拡張機能のバージョン、アクション、編集されたエラーが含まれます。セッション Cookie、資格情報、プライベート ターゲット、CA 秘密キー、または生の機密レポートは送信しないでください。この Web サイトには問い合わせフォームが含まれておらず、サポートの提出も収集されていません。

マーケットプレイスのステータス

ブラウザのパッケージ化と自動チェックはマーケットプレイスの承認を構成しません。ストアの掲載情報、配布、署名は発行者のアカウントを通じて管理されます。
