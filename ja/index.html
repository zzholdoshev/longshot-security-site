Longshot は、所有している Web アプリケーションまたはテストを許可されている Web アプリケーションのセキュリティの弱点を見つけるための Firefox および Chrome 拡張機能です。これは、ブラウザー セッションのスキャン、ファジング、脆弱性テンプレート、証拠が豊富なレポートを組み合わせたものです。オプションのブラウザ ブリッジを使用すると、ZAP やcurl などのツールが、設定可能なブラウザ Cookie とヘッダーのオーバーライドを使用して独自の HTTP リクエストを送信できるようになります。
