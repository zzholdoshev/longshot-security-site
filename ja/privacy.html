ロングショットのプライバシーとデータの処理

パブリッシャーの表示名: Longshot Security。 Longshot の Firefox および Chrome エディションに適用されます。 Longshot は、認定された Web セキュリティ評価のためのワークベンチです。これには、開発者の分析、広告、または開発者が運営するスキャン アップロード サービスは含まれません。この拡張機能には開発者アカウントは必要ありません。

使用データ

ターゲットに接続すると、Longshot はそのアドレス、ページ コンテンツ、検出されたエンドポイント、HTTP メタデータ、サポートされているスキャナーのリクエスト/応答本体、検出結果、およびレビュー メモを処理します。接続されたブラウザー タブは、評価のセッションを提供します。さらに、ブラウザ ブリッジは、HttpOnly Cookie を含む該当する Cookie 値、およびペアになったタブの Cookie ストアから明示的に選択された観察された認証/ヘッダー値を読み取ることができます。これらの値により、ローカル ツールによる認証リクエストが有効になります。

評価証拠、ターゲット プロファイル、および設定は、拡張ストレージ/IndexedDB にローカルに保存されます。オプションで保持される応答には、ベストエフォートの編集にもかかわらず、アプリケーション情報が含まれる場合があります。オプションのエクスポートされたレポート/セッション ファイルは、選択した場所に書き込まれるかダウンロードされますが、Longshot によって暗号化されません。ローカル ブラウザーの Cookie jar は、評価エクスポートとは別のものです。

データの行き先

  • ブラウザ スキャンでは、選択したテスト リクエストが、構成されたスコープと制限に従って接続されたターゲットに送信されます。ライブ ターゲット ページを開くと、ブラウザを通じて通常のリソースが読み込まれます。
  • ブラウザ ブリッジはオプションです。ペアリングは、個別に起動されたローカル ネイティブ アダプターを明示的に接続します。該当する Cookie とオプトイン ヘッダーが認証されたループバック ヘルパーに送信され、発信ツール リクエストが形成されます。応答 Cookie の同期はデフォルトで有効になっており、個別に無効にすることができます。ターゲット トラフィックは、アダプターの構成された直接/アップストリーム/SOCKS ルートに従います。外部ツールは独自の履歴を保持できます。使用する前に設定を確認してください。
  • エージェント API/ネイティブ メッセージングはオプションであり、個別のネイティブ ホストのインストールと接続が必要です。これにより、エージェントを含む認証されたローカル クライアントがワークベンチを操作し、結果を受け取り、明示的に設定されたセッション ファイル/ネイティブ テンプレート機能を使用できるようになります。完全な UI 自動化により、承認ダイアログを操作できます。これらのローカル インターフェイスへのアクセスを特権付きとして扱います。
  • OAST はオプションであり、構成したプロバイダーに接続します。登録/ポーリング、コールバック相関、およびターゲットによってトリガーされる対話により、接続/IP およびプローブのメタデータがそのプロバイダーに開示される可能性があります。プロバイダーには独自のポリシーがあります。コールバック ドメインまたはプロバイダー トークンは Longshot 開発者サービスには送信されません。
  • GitHub リストの更新は、Cookie が省略された固定パブリック ペイロード/テンプレート ソースを取得する明示的なアクションです。ターゲット URL、応答本文、Cookie、アップロードされたカスタム パックは、そのアクションによって GitHub に送信されません。
  • オンライン CVE ルックアップは、サポートされている製品/パッケージの座標を使用して NVD/OSV をクエリする明示的なアクションです。ターゲット URL、ページ、セッション Cookie は送信されません。プロバイダーはソフトウェア座標と通常の接続メタデータを受け取ります。
  • レポート/セッション/テーマのエクスポートは、対応するユーザーまたは認証された自動化アクションを通じてのみ行われます。これらのファイルを共有するかどうかはあなたの判断です。

ブラウザ データは、限定使用要件を含む Chrome ウェブストア ユーザー データ ポリシーに基づいて、開示されたセキュリティ評価機能のためにのみ使用/転送されます。評価データを販売したり、広告、クレジット、無関係なプロファイリング、開発者モデルのトレーニングに使用したりすることはありません。バンドルされた UI 翻訳は、実行時にオンライン翻訳を呼び出しません。オプションのローカル モデル/MCP クライアントは個別に構成され、独自のデータ処理を行います。

制御と保持

[設定] → [スキャン データのクリア] を使用して、アクティブなプロファイルのスキャン証拠をクリアします。ワークベンチを通じてプロファイルとインポートされた素材を管理します。拡張機能を削除すると、ブラウザーが所有する拡張機能ストレージが削除されます。エクスポートされたレポート、ネイティブ監査ディレクトリ、CA キー、およびオプションのセッション ファイルは、保存されている場所から個別に削除します。 Longshot は評価アップロード バックエンドを運用していないため、開発者の保持期間は存在しません。

プロキシのリクエスト Cookie のオーバーライド、レスポンス Cookie の同期、およびヘッダー ソーシングは別個の制御です。 1 つを無効にしても、別の統合が停止するという保証はありません。関連するローカル ヘルパーを停止または切断し、使用可能にしたくない場合はネイティブ登録を削除します。ブラウザの権限を取り消すと、依存する機能が無効になる場合があります。

Chrome スキャンとネイティブのペアリングは、ユーザーに表示されるワークベンチが開いたまま実行されます。これを閉じると、ライブ エンジンの作業が終了します。永続的な証拠が残っています。 Firefox は、宣言された永続的な背景ページを使用します。このリリースでは、Chrome エディションではシークレット操作が許可されていません。 Firefox のプライベート/コンテナー コンテキストは、選択されており、ブラウザーのアクセスが許可されている場合にのみ使用されます。

権限

ホスト アクセス、タブ、およびスクリプト インジェクションは、任意の承認されたターゲットへの接続とそのページの検査/テストをサポートします。 webRequest は、スコープ付きタブの HTTP メタデータを監視します。開発者の閲覧履歴分析には使用されません。 Cookie は、ペア化されたネイティブ セッション機能をサポートします。ストレージにはローカルの証拠/設定が保持されます。通知は評価の注意を報告します。ネイティブ メッセージングは​​、個別にインストールされたエージェント API ホストではオプションです。 Firefox のオプションのブロック許可は、明示的なインターセプター/ライブ DOM ガードをサポートします。 Chrome によって要求されたものではありません。

ローカル ヘルパーは認証/オリジン チェックとループバック リスナーを使用しますが、メモリ内のセッション シークレットを処理できます。 Cookie 共有は、ブラウザーと同一の TLS/IP ルーティング、WAF の受け入れ、または自動的に安全にインポートされたプログラムを保証するものではありません。有効にする前に、統合、作成されたペイロード/テンプレート、および対象となるターゲットを確認してください。

このウェブサイト

この静的な Longshot Web サイトには、分析スクリプト、サードパーティの広告、お問い合わせフォーム、評価アップロード サービスはありません。 GitHub Pages はこれをホストし、セキュリティ目的で訪問者の IP アドレスを記録します。参照 GitHub ページのデータ収集 そして GitHub のプライバシーに関する声明。ブラウザ ストアと GitHub の発行ページには、独自のデータ処理があります。
