A SECOND OPINION FOR YOUR RUNNING APP

Longshot is a Firefox and Chrome extension for finding security weaknesses in web applications you own or are authorized to test. It combines browser-session scanning, fuzzing, vulnerability templates, and evidence-rich reports. Its optional Browser Bridge lets tools such as ZAP and curl send their own HTTP requests with configurable browser-cookie and header overrides.
