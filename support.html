Longshot support

Start with the connected tab

Open your authorized target, sign in, launch Longshot from that tab and Connect. Use Information and Getting started for the current release workflow. A public HTTP 200 page does not prove authentication; configure a protected validator.

Native bridge

The Browser Bridge Information guide explains the separate Node/Python adapter, exact extension origin, proxy/control ports, token and HTTPS CA trust. Use real target URLs; no bridge.invalid or hosts-file entry is needed. Cookie overrides and response synchronization are independent. A rotating stale cookie can be mistaken for a scanner probe; disable automatic change preservation when Firefox/Chrome's jar must stay authoritative and explicitly protect deliberate test fields.

Chrome and Firefox differences

Chrome uses Manifest V3 and requires the visible workbench to remain open. The current Chrome build explicitly disables the listed Firefox-only blocking, live-DOM, container and background-capture capabilities. Firefox retains its supported platform capabilities. Read the in-product capability note instead of assuming identical coverage.

Reports and data removal

Review captured application data before exporting or sharing. Clear the active assessment in Settings; delete optional exported/native files where they were saved. The privacy page explains storage and integrations.

Reporting an issue

Open a public support issue, or use the developer/publisher contact in the browser store listing once the extension is listed. GitHub issues are public; a GitHub account is needed to submit one. Include browser/extension versions, the action and a redacted error. Do not send session cookies, credentials, private targets, CA private keys or raw sensitive reports. This website does not contain a contact form or collect support submissions.

Marketplace status

Browser packaging and automated checks do not constitute marketplace approval. Store listings, distribution and signing are managed through the publisher's account.
