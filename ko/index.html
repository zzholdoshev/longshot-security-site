Longshot은 소유하거나 테스트 허가를 받은 웹 애플리케이션의 취약점 점검을 돕는 Firefox·Chrome 확장 프로그램입니다. 브라우저 세션을 활용한 스캔, 퍼징, 검사 템플릿, 근거가 담긴 보고서를 한곳에서 제공합니다. 선택 기능인 Browser Bridge를 사용하면 ZAP, curl 같은 도구가 자체 HTTP 요청을 보내면서, 필요한 경우 브라우저의 쿠키와 헤더를 적용할 수 있습니다.

01 / 브라우저 브리지

내가 쓰던 도구.
지금 열린 탭.
로그인된 세션 그대로.

ZAP, curl, sqlmap 등의 HTTP 도구는 로컬 프록시를 통해 자체 요청을 보냅니다. 브라우저 쿠키는 기본으로 적용되며, 나머지 요청 설정은 직접 선택할 수 있습니다.

브라우저 브리지 살펴보기 ↗선택적 컴패니언 설정이 필요합니다.
02 / AI + MCP

코드는 AI가 썼는데,
검증은 누가 했나요?

MCP 호환 에이전트를 연결해 실행 중인 앱을 살펴보고, 허가된 검사를 실행하고, 결과를 분석하세요. AI의 판단을 실제 근거와 대조해 볼 수 있습니다.

상담원 워크플로를 만나보세요 ↗
03 / 조사 결과 + 보고서

취약점을 찾고,
근거로 설명하세요.

능동 검사, 퍼징, 호환 CVE 템플릿, OAST로 잠재적인 취약점의 단서를 찾습니다. 요청과 발견 사항을 검토한 뒤 보고서나 시각적 설명으로 공유하세요.
