Longshot 개인 정보 보호 및 데이터 처리

게시자 표시 이름: Longshot Security. Longshot의 Firefox 및 Chrome 버전에 적용됩니다. Longshot은 인증된 웹 보안 평가를 위한 워크벤치입니다. 여기에는 개발자 분석, 광고 또는 개발자가 운영하는 스캔 업로드 서비스가 포함되어 있지 않습니다. 확장 프로그램에는 개발자 계정이 필요하지 않습니다.

사용된 데이터

대상을 연결한 후 Longshot은 해당 주소, 페이지 콘텐츠, 검색된 엔드포인트, HTTP 메타데이터, 지원되는 스캐너 요청/응답 본문, 결과 및 검토 메모를 처리합니다. 연결된 브라우저 탭은 평가 세션을 제공합니다. 브라우저 브리지는 HttpOnly 쿠키를 포함하여 적용 가능한 쿠키 값과 쌍을 이루는 탭의 쿠키 저장소에서 명시적으로 선택된 관찰된 인증/헤더 값을 추가로 읽을 수 있습니다. 이러한 값을 사용하면 로컬 도구를 통해 인증된 요청을 사용할 수 있습니다.

평가 증거, 대상 프로필 및 기본 설정은 확장 저장소/IndexedDB에 로컬로 저장됩니다. 선택적 보유 응답에는 최선의 편집에도 불구하고 애플리케이션 정보가 포함될 수 있습니다. 선택적으로 내보낸 보고서/세션 파일은 선택한 위치에 기록되거나 다운로드되며 Longshot에 의해 암호화되지 않습니다. 로컬 브라우저 쿠키 jar는 평가 내보내기와 별개입니다.

데이터가 가는 곳

  • 브라우저 스캐닝은 선택된 테스트 요청을 구성된 범위 및 제한에 따라 연결된 대상으로 보냅니다. 라이브 대상 페이지를 열면 브라우저를 통해 일반 리소스가 로드됩니다.
  • 브라우저 브리지는 선택 사항입니다. 페어링은 별도로 시작된 로컬 기본 어댑터를 명시적으로 연결합니다. 적용 가능한 쿠키와 옵트인 헤더는 인증된 루프백 도우미로 전송되어 나가는 도구 요청을 구성합니다. 응답 쿠키 동기화는 기본적으로 활성화되어 있으며 독립적으로 비활성화할 수 있습니다. 그런 다음 대상 트래픽은 어댑터에 구성된 직접/업스트림/SOCKS 경로를 따릅니다. 외부 도구는 자체 기록을 유지할 수 있습니다. 사용하기 전에 설정을 확인하십시오.
  • 에이전트 API/기본 메시징은 선택 사항이며 별도의 기본 호스트 설치 및 연결이 필요합니다. 이를 통해 에이전트를 포함한 인증된 로컬 클라이언트가 워크벤치를 작동하고 결과를 수신하며 명시적으로 구성된 세션 파일/네이티브 템플릿 기능을 사용할 수 있습니다. 전체 UI 자동화는 승인 대화 상자를 작동할 수 있습니다. 해당 로컬 인터페이스에 대한 액세스를 특권으로 취급하십시오.
  • OAST는 선택 사항이며 구성한 공급자에게 문의하세요. 등록/폴링, 콜백 상관 관계 및 대상에 의해 트리거되는 상호 작용을 통해 해당 공급자에게 연결/IP 및 프로브 메타데이터가 공개될 수 있습니다. 공급자는 자체 정책을 가지고 있습니다. 콜백 도메인 또는 공급자 토큰은 Longshot 개발자 서비스로 전송되지 않습니다.
  • GitHub 목록 업데이트는 쿠키가 생략된 고정된 공개 페이로드/템플릿 소스를 가져오는 명시적인 작업입니다. 대상 URL, 응답 본문, 쿠키 및 업로드된 사용자 정의 팩은 해당 작업으로 인해 GitHub로 전송되지 않습니다.
  • 온라인 CVE 조회는 지원되는 제품/패키지 좌표를 사용하여 NVD/OSV를 쿼리하는 명시적인 작업입니다. 대상 URL, 페이지 또는 세션 쿠키를 보내지 않습니다. 공급자는 소프트웨어 좌표와 일반 ​​연결 메타데이터를 받습니다.
  • 보고서/세션/테마 내보내기는 해당 사용자 또는 인증된 자동화 작업을 통해서만 발생합니다. 해당 파일을 공유하는 것은 귀하의 결정입니다.

브라우저 데이터는 제한된 사용 요구 사항을 포함하여 Chrome 웹 스토어 사용자 데이터 정책에 따라 공개된 보안 평가 기능을 위해서만 사용/전송됩니다. 평가 데이터를 판매하거나 광고, 신용, 관련 없는 프로파일링 또는 개발자 모델 교육을 위해 사용하지 않습니다. 번들 UI 번역은 런타임 시 온라인 번역기를 호출하지 않습니다. 선택적 로컬 모델/MCP 클라이언트는 독립적으로 구성되며 자체 데이터 처리 기능을 갖습니다.

통제 및 보존

설정 → 스캔 데이터 지우기를 사용하여 활성 프로필의 스캔 증거를 지웁니다. 워크벤치를 통해 프로필과 가져온 자료를 관리합니다. 확장 프로그램을 제거하면 브라우저 소유의 확장 저장소가 제거됩니다. 내보낸 보고서, 기본 감사 디렉터리, CA 키 및 선택적 세션 파일을 저장된 위치에서 별도로 삭제합니다. Longshot은 평가 업로드 백엔드를 운영하지 않기 때문에 개발자 보존 기간이 없습니다.

프록시 요청-쿠키 재정의, 응답-쿠키 동기화 및 헤더 소싱은 별도의 제어입니다. 하나를 비활성화한다고 해서 다른 통합이 중단된다는 보장은 없습니다. 관련 로컬 도우미를 중지/연결 해제하고 더 이상 사용하지 않으려면 기본 등록을 제거하세요. 브라우저 권한을 취소하면 종속 기능이 비활성화될 수 있습니다.

사용자에게 표시되는 워크벤치가 열려 있는 동안 Chrome 스캔/네이티브 페어링이 실행됩니다. 닫으면 실제 엔진 작업이 종료됩니다. 지속적인 증거가 남아 있습니다. Firefox는 선언된 영구 배경 페이지를 사용합니다. Chrome 버전은 이번 릴리스에서 시크릿 작업을 허용하지 않습니다. Firefox 개인/컨테이너 컨텍스트는 선택되어 있고 브라우저 액세스가 이를 허용하는 경우에만 사용됩니다.

권한

호스트 액세스, 탭 및 스크립트 주입은 임의의 승인된 대상에 연결하고 해당 페이지를 검사/테스트하는 것을 지원합니다. webRequest는 범위가 지정된 탭의 HTTP 메타데이터를 관찰합니다. 개발자 검색 기록 분석에는 사용되지 않습니다. 쿠키는 페어링된 기본 세션 기능을 지원합니다. 스토리지는 로컬 증거/선호도를 유지합니다. 알림은 평가 주의 사항을 보고합니다. 기본 메시징은 별도로 설치된 에이전트 API 호스트의 경우 선택 사항입니다. Firefox의 선택적 차단 권한은 명시적인 인터셉터/live-DOM 가드를 지원합니다. Chrome에서는 요청하지 않습니다.

로컬 헬퍼는 인증/원본 확인 및 루프백 리스너를 사용하지만 메모리의 세션 비밀을 처리할 수 있습니다. 쿠키 공유는 브라우저와 동일한 TLS/IP 라우팅, WAF 허용 또는 자동으로 안전한 가져오기 프로그램을 보장하지 않습니다. 활성화하기 전에 통합, 작성된 페이로드/템플릿 및 의도한 대상을 검토하세요.

이 웹사이트

이 정적 Longshot 웹사이트에는 분석 스크립트, 제3자 광고, 문의 양식 또는 평가 업로드 서비스가 없습니다. GitHub Pages는 이를 호스팅하고 보안 목적으로 방문자의 IP 주소를 기록합니다. 참조 GitHub 페이지 데이터 수집 그리고 GitHub 개인정보 보호정책. 브라우저 저장소 및 GitHub 문제 페이지에는 자체 데이터 처리 기능이 있습니다.

출판사 연락처

게시자 표시 이름: Longshot Security. 참조 지원 설정 도움말을 보려면 공개 지원 문제 추적기 수정된 질문이 있는 경우 해당 브라우저 스토어 목록의 게시자에게 문의하세요. 문제는 공개됩니다. 자격 증명, 개인 목표 또는 평가 증거를 포함하지 마십시오. 이 표시 이름으로는 매장 승인이나 등록된 회사 상태를 주장하지 않습니다.

Longshot 보안 · 승인된 평가만 가능 · 분석 또는 광고 추적기 없음.

번역은 기계로 생성됩니다. 영어 버전이 참고 자료입니다.
