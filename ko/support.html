연결된 탭으로 시작

승인된 타겟을 열고 로그인한 후 해당 탭에서 Longshot을 실행하고 연결하세요. 현재 릴리스 워크플로에 대한 정보 및 시작하기를 사용하세요. 공개 HTTP 200 페이지는 인증을 증명하지 않습니다. 보호된 유효성 검사기를 구성합니다.

네이티브 브리지

브라우저 브리지 정보 가이드에서는 별도의 노드/Python 어댑터, 정확한 확장 원본, 프록시/제어 포트, 토큰 및 HTTPS CA 신뢰에 대해 설명합니다. 실제 대상 URL을 사용하세요. bridge.invalid 또는 호스트 파일 항목이 필요하지 않습니다. 쿠키 재정의와 응답 동기화는 독립적입니다. 회전하는 오래된 쿠키는 스캐너 프로브로 오해될 수 있습니다. Firefox/Chrome의 jar가 신뢰성을 유지하고 의도적인 테스트 필드를 명시적으로 보호해야 하는 경우 자동 변경 보존을 비활성화합니다.

크롬과 파이어폭스의 차이점

Chrome은 Manifest V3를 사용하며 눈에 보이는 워크벤치가 열려 있어야 합니다. 현재 Chrome 빌드는 나열된 Firefox 전용 차단, 라이브 DOM, 컨테이너 및 배경 캡처 기능을 명시적으로 비활성화합니다. Firefox는 지원되는 플랫폼 기능을 유지합니다. 동일한 적용 범위를 가정하는 대신 제품 내 기능 참고 사항을 읽으십시오.

보고서 및 데이터 제거

내보내거나 공유하기 전에 캡처된 애플리케이션 데이터를 검토하세요. 설정에서 활성 평가를 지웁니다. 저장된 선택적 내보내기/네이티브 파일을 삭제합니다. 개인정보 보호 페이지에서는 저장 및 통합에 대해 설명합니다.

문제 보고

열기 대중의 지지 문제, 또는 확장 프로그램이 나열되면 브라우저 스토어 목록의 개발자/게시자 연락처를 사용하세요. GitHub 문제는 공개되어 있습니다. 제출하려면 GitHub 계정이 필요합니다. 브라우저/확장 버전, 작업 및 수정된 오류를 포함합니다. 세션 쿠키, 자격 증명, 개인 대상, CA 개인 키 또는 민감한 원시 보고서를 보내지 마십시오. 이 웹사이트에는 문의 양식이 포함되어 있지 않으며 지원 제출물을 수집하지도 않습니다.

마켓플레이스 상태

브라우저 패키징 및 자동 검사는 시장 승인을 의미하지 않습니다. 스토어 목록, 배포 및 서명은 게시자의 계정을 통해 관리됩니다.

Longshot 보안 · 승인된 평가만 가능 · 분석 또는 광고 추적기 없음.
