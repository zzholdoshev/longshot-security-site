Конфиденциальность и обработка данных в долгосрочной перспективе

Отображаемое имя издателя: Longshot Security. Применяется к версиям Longshot для Firefox и Chrome. Longshot — это инструмент для авторизованной оценки веб-безопасности. Он не содержит аналитики разработчиков, рекламы или службы загрузки отсканированных изображений, управляемой разработчиком. Для расширения не требуется учетная запись разработчика.

Используемые данные

После подключения цели Longshot обрабатывает ее адрес, содержимое страницы, обнаруженные конечные точки, метаданные HTTP, тела запросов/ответов поддерживаемого сканера, выводы и примечания к проверке. Подключенная вкладка браузера обеспечивает сеанс оценивания. Browser Bridge может дополнительно считывать применимые значения файлов cookie, включая файлы cookie HttpOnly, а также явно выбирать наблюдаемые значения аутентификации/заголовка из хранилища файлов cookie парной вкладки. Эти значения позволяют вашим локальным инструментам выполнять запросы с проверкой подлинности.

Свидетельства оценки, целевые профили и предпочтения хранятся локально в хранилище расширений/IndexedDB. Необязательные сохраненные ответы могут содержать информацию о приложении, несмотря на все возможные изменения. Дополнительные экспортированные отчеты/файлы сеансов записываются или загружаются в любое место по вашему выбору и не шифруются Longshot. Файл cookie локального браузера отделен от экспорта оценок.

Куда идут данные

  • Сканирование браузера отправляет выбранные вами тестовые запросы на подключенную цель в соответствии с настроенной областью и ограничениями. Открытие активных целевых страниц загружает их обычные ресурсы через браузер.
  • Браузерный мост не является обязательным. Сопряжение явно подключает отдельно запущенный локальный собственный адаптер. Применимые файлы cookie и включенные заголовки отправляются этому проверенному помощнику обратной связи для формирования исходящих запросов инструментов. Синхронизация файлов cookie ответа включена по умолчанию и может быть отключена независимо. Целевой трафик затем следует по настроенному адаптеру прямому/восходящему маршруту/SOCKS-маршруту. Внешние инструменты могут хранить свою собственную историю; проверьте их настройки перед использованием.
  • API агента/собственный обмен сообщениями являются необязательными и требуют отдельной установки и подключения на собственном хосте. Это позволяет аутентифицированным локальным клиентам, включая ваших агентов, управлять рабочей средой, получать результаты и использовать явно настроенные функции файла сеанса/собственного шаблона. Полная автоматизация пользовательского интерфейса позволяет управлять диалогом утверждения. Считайте доступ к этим локальным интерфейсам привилегированным.
  • OAST является необязательным и связывается с провайдером, которого вы настроили. Регистрация/опрос, корреляция обратных вызовов и целевые взаимодействия могут раскрывать соединение/IP-адрес и проверять метаданные этому провайдеру. У провайдера своя политика. Домен обратного вызова или токен поставщика не отправляются в службу разработчиков Longshot.
  • Обновление списков GitHub — это явное действие, извлекающее фиксированные общедоступные источники полезных данных/шаблонов без файлов cookie. Целевые URL-адреса, тексты ответов, файлы cookie и загруженные пользовательские пакеты не отправляются в GitHub в результате этого действия.
  • Онлайн-поиск CVE — это явное действие, запрашивающее NVD/OSV с поддерживаемыми координатами продукта/пакета. Он не отправляет целевые URL-адреса, страницы или файлы cookie сеанса; провайдер получает программные координаты и обычные метаданные соединения.
  • Экспорт отчета/сеанса/темы осуществляется только посредством соответствующего пользователя или аутентифицированного действия автоматизации. Делиться этими файлами – ваше решение.

Данные браузера используются/передаются исключительно для раскрытых функций оценки безопасности в соответствии с Политикой пользовательских данных Интернет-магазина Chrome, включая требования ограниченного использования. Данные оценки не продаются и не используются для рекламы, кредитования, несвязанного профилирования или обучения моделей разработчиков. Пакетные переводы пользовательского интерфейса не вызывают онлайн-переводчик во время выполнения. Дополнительные клиенты локальной модели/MCP настраиваются независимо и имеют собственную обработку данных.

Контроль и удержание

Используйте «Настройки» → «Очистить данные сканирования», чтобы удалить доказательства сканирования активного профиля. Управляйте профилями и импортированными материалами через верстак; удаление расширения удаляет принадлежащее браузеру хранилище расширений. Удалите экспортированные отчеты, собственные каталоги аудита, ключи CA и дополнительные файлы сеансов отдельно там, где они были сохранены. Срок хранения для разработчиков не существует, поскольку Longshot не использует серверную часть для загрузки оценок.

Переопределение файлов cookie запроса прокси, синхронизация файлов cookie ответа и источник заголовка — это отдельные элементы управления. Отключение одного из них не означает, что другая интеграция прекратится. Остановите/отключите соответствующий локальный помощник и удалите его собственную регистрацию, если вы больше не хотите, чтобы он был доступен. Отзыв разрешений браузера может привести к отключению зависимых функций.

Сканирование Chrome и встроенное сопряжение выполняются, пока видимая пользователем рабочая среда остается открытой. Закрытие его прекращает работу двигателя; устойчивые доказательства остаются. Firefox использует заявленную постоянную фоновую страницу. Версия Chrome не поддерживает работу в режиме инкогнито в этом выпуске; Контексты частного/контейнера Firefox используются только в том случае, если они выбраны и доступ к браузеру разрешает их.

Разрешения

Доступ к хосту, поддержка вкладок и внедрения сценариев, подключение произвольной авторизованной цели и проверка/тестирование ее страниц. webRequest отслеживает метаданные HTTP вкладки с заданной областью; он не используется для анализа истории просмотров разработчиками. Файлы cookie поддерживают функцию парного встроенного сеанса. В хранилище сохраняются локальные данные/предпочтения. Уведомления сообщают об оценке внимания. Собственный обмен сообщениями не является обязательным для отдельно установленного узла API агента. Дополнительное разрешение блокировки Firefox поддерживает явные средства защиты перехватчика/live-DOM; Chrome не запрашивает его.

Локальные помощники используют проверки аутентификации/источника и прослушиватели обратной связи, но могут обрабатывать секреты сеанса в памяти. Совместное использование файлов cookie не гарантирует идентичную маршрутизацию TLS/IP браузера, принятие WAF или автоматическую безопасность импортированных программ. Прежде чем включать их, просмотрите интеграции, авторские полезные нагрузки/шаблоны и намеченные цели.

Этот сайт

GitHub Pages размещает его и регистрирует IP-адреса посетителей в целях безопасности. См. Сбор данных GitHub Pages и Заявление о конфиденциальности GitHub. Страницы магазина браузера и GitHub имеют собственную обработку данных.
