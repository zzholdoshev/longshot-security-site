Начните с подключенной вкладки

Откройте авторизованную цель, войдите в систему, запустите Longshot с этой вкладки и подключитесь. Используйте информацию и начало работы для рабочего процесса текущего выпуска. Публичная страница HTTP 200 не подтверждает аутентификацию; настроить защищенный валидатор.

Родной мост

В руководстве «Информация о мосте браузера» объясняется отдельный адаптер Node/Python, точный источник расширения, порты прокси-сервера/управления, токен и доверие CA HTTPS. Используйте реальные целевые URL-адреса; запись в файле Bridge.invalid или Hosts не требуется. Переопределение файлов cookie и синхронизация ответов независимы. Вращающийся устаревший файл cookie можно принять за зонд сканера; отключить автоматическое сохранение изменений, когда jar Firefox/Chrome должен оставаться авторитетным и явно защищать намеренные тестовые поля.

Различия Chrome и Firefox

Chrome использует Manifest V3 и требует, чтобы видимая рабочая среда оставалась открытой. Текущая сборка Chrome явно отключает перечисленные возможности блокировки только для Firefox, Live-DOM, контейнеров и фонового захвата. Firefox сохраняет возможности поддерживаемой платформы. Прочтите примечание о возможностях продукта вместо того, чтобы предполагать идентичное покрытие.

Отчеты и удаление данных

Просмотрите захваченные данные приложения перед экспортом или обменом ими. Очистите активную оценку в Настройках; удалите необязательные экспортированные/собственные файлы, в которых они были сохранены. На странице конфиденциальности объясняется хранение и интеграция.

Сообщить о проблеме

Откройте проблема общественной поддержкиили используйте контакт разработчика/издателя в списке магазина браузера, как только расширение появится в списке. Проблемы GitHub являются общедоступными; Для отправки необходима учетная запись GitHub. Укажите версии браузера/расширения, действие и отредактированную ошибку. Не отправляйте файлы cookie сеанса, учетные данные, частные цели, закрытые ключи CA или необработанные конфиденциальные отчеты. Этот веб-сайт не содержит контактной формы и не предназначен для сбора обращений в службу поддержки.
