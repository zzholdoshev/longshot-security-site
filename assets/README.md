# Website asset provenance

- protect-your-build.webp, browser-bridge.webp, ai-mcp.webp and evidence-reports.webp: publisher-supplied Longshot campaign pictures from ~/Pictures, encoded to WebP for delivery. Composition content is unchanged.
- mark.svg: Longshot bow/arrow identity adapted in site code to the extension default red accent.
- The Scout mascot is original SVG geometry embedded in index.html, animated using site.css/site.js presentation code (stylesheet filename: style.css). No Claude mascot asset is used.
- memory-threads.svg: from the extension’s bundled default theme.
- Rajdhani-SemiBold.woff2 and IBMPlexMono-Regular.woff2: WOFF2 encodings of bundled font files; their original OFL licenses are retained in this directory.
- Documentation screenshots under docs/assets are owned-fixture captures from the 2.18.1 Firefox validation run.
