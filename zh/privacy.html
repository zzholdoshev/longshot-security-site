Longshot Security文档隐私支持

远景隐私和数据处理

发布者显示名称：Longshot Security。适用于 Longshot 的 Firefox 和 Chrome 版本。 Longshot 是一个用于授权 Web 安全评估的工作台。它不包含开发人员分析、广告或开发人员运营的扫描上传服务。该扩展不需要开发者帐户。

使用的数据

连接目标后，Longshot 会处理其地址、页面内容、发现的端点、HTTP 元数据、支持的扫描仪请求/响应正文、结果和审阅注释。连接的浏览器选项卡提供评估会话。浏览器桥还可以读取适用的 cookie 值，包括 HttpOnly cookie，以及从配对选项卡的 cookie 存储中显式选择的观察到的身份验证/标头值。这些值允许您的本地工具对请求进行身份验证。

评估证据、目标概况和偏好存储在本地扩展存储/IndexedDB 中。尽管尽最大努力进行编辑，可选的保留响应仍可以包含应用程序信息。可选导出的报告/会话文件在您选择的位置写入或下载，且不会由 Longshot 加密。本地浏览器 cookie jar 与评估导出是分开的。

数据去向

  • 浏览器扫描将您选择的测试请求发送到配置的范围和限制下的连接目标。打开实时目标页面通过浏览器加载其正常资源。
  • 浏览器桥是可选的。配对显式连接单独启动的本地本机适配器。适用的 cookie 和选择加入的标头将发送到经过身份验证的环回帮助程序，以形成传出工具请求。响应 cookie 同步默认启用，并且可以单独禁用。然后，目标流量遵循适配器配置的直接/上游/SOCKS 路由。外部工具可以保留自己的历史记录；使用前检查其设置。
  • 代理 API/本机消息传递是可选的，需要单独的本机主机安装和连接。它允许经过身份验证的本地客户端（包括您的代理）操作工作台、接收结果并使用显式配置的会话文件/本机模板功能。完全的 UI 自动化可以操作批准对话框。将对这些本地接口的访问视为特权。
  • OAST 是可选的，它会联系您配置的提供商。注册/轮询、回调关联和目标触发的交互可以向该提供商公开连接/IP 和探测元数据。提供商有自己的政策。回调域或提供商令牌不会发送到 Longshot 开发人员服务。
  • 更新 GitHub 列表是一个显式操作，用于获取固定的公共有效负载/模板源，并省略 cookie。该操作不会将目标 URL、响应正文、Cookie 和上传的自定义包发送到 GitHub。
  • 在线 CVE 查找是查询 NVD/OSV 以及受支持的产品/包坐标的显式操作。它不发送目标 URL、页面或会话 cookie；提供商接收软件坐标和普通连接元数据。
  • 报告/会话/主题导出仅通过相应的用户或经过身份验证的自动化操作进行。共享这些文件是您的决定。

根据 Chrome 网上应用店用户数据政策（包括有限使用要求），浏览器数据仅用于所披露的安全评估功能。不出售评估数据，也不将其用于广告、信用、不相关的分析或开发者模型培训。捆绑的 UI 翻译不会在运行时调用在线翻译器。可选的本地模型/MCP 客户端独立配置并具有自己的数据处理。

控制和保留

使用设置 → 清除扫描数据来清除活动配置文件的扫描证据。通过工作台管理配置文件和导入的材料；删除扩展程序会删除其浏览器拥有的扩展程序存储。分别删除保存导出的报告、本机审核目录、CA 密钥和可选会话文件。由于 Longshot 不运行评估上传后端，因此不存在开发人员保留期。

代理请求 cookie 覆盖、响应 cookie 同步和标头来源是单独的控制。禁用一个集成并不意味着另一个集成就会停止。如果您不再需要它可用，请停止/断开相关本地帮助程序并删除其本机注册。撤销浏览器权限可以禁用相关功能。

Chrome 扫描/本机配对在用户可见的工作台保持打开状态时运行。关闭它会结束引擎的实时工作；证据仍然存在。 Firefox 使用其声明的持久后台页面。 Chrome 版本不允许在此版本中进行隐身操作； Firefox 私有/容器上下文仅在选择且浏览器访问允许时使用。

权限

主机访问、选项卡和脚本注入支持连接任意授权目标并检查/测试其页面。 webRequest 观察范围选项卡的 HTTP 元数据；它不用于开发人员浏览历史记录分析。 Cookie 支持配对本机会话功能。存储保留本地证据/偏好。通知报告评估关注。对于单独安装的代理 API 主机，本机消息传递是可选的。 Firefox 的可选阻止权限支持其显式拦截器/live-DOM 防护； Chrome 不要求它。

本地帮助程序使用身份验证/来源检查和环回侦听器，但可以在内存中处理会话机密。 Cookie 共享不保证浏览器相同的 TLS/IP 路由、WAF 接受或自动安全导入的程序。在启用之前检查集成、编写的有效负载/模板和预期目标。

这个网站

这个静态的 Longshot 网站没有分析脚本、第三方广告、联系表格或评估上传服务。 GitHub Pages 托管它并记录访问者的 IP 地址以确保安全。参见 GitHub Pages 数据收集 和 GitHub 隐私声明。浏览器存储和 GitHub 问题页面有自己的数据处理。
