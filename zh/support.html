Longshot 使用支持

从连接的选项卡开始

打开您的授权目标，登录，从该选项卡启动 Longshot 并连接。使用当前发布工作流程的信息和入门。公共 HTTP 200 页面不证明身份验证；配置受保护的验证器。

原生桥

浏览器桥信息指南解释了单独的 Node/Python 适配器、确切的扩展源、代理/控制端口、令牌和 HTTPS CA 信任。使用真实的目标 URL；不需要bridge.invalid 或hosts 文件条目。 Cookie 覆盖和响应同步是独立的。旋转的陈旧 cookie 可能会被误认为是扫描仪探针；当 Firefox/Chrome 的 jar 必须保持权威并显式保护有意的测试字段时，禁用自动更改保存。

Chrome 和 Firefox 的区别

Chrome 使用 Manifest V3 并要求可见工作台保持打开状态。当前的 Chrome 版本明确禁用了列出的仅限 Firefox 的阻止、实时 DOM、容器和后台捕获功能。 Firefox 保留其支持的平台功能。请阅读产品内的功能说明，而不是假设覆盖范围相同。

报告和数据删除

在导出或共享之前查看捕获的应用程序数据。清除设置中的主动评估；删除保存它们的可选导出/本机文件。隐私页面解释了存储和集成。

报告问题

打开一个 公众支持问题，或者在列出扩展程序后使用浏览器商店列表中的开发者/发布者联系人。 GitHub 问题是公开的；需要有 GitHub 帐户才能提交。包括浏览器/扩展版本、操作和已编辑的错误。请勿发送会话 cookie、凭据、私有目标、CA 私钥或原始敏感报告。该网站不包含联系表格或收集支持意见。
