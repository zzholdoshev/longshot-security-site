Inizia con la scheda connessa

Apri il tuo target autorizzato, accedi, avvia Longshot da quella scheda e Connetti. Utilizzare Informazioni e Guida introduttiva per il flusso di lavoro della versione corrente. Una pagina HTTP 200 pubblica non dimostra l'autenticazione; configurare un validatore protetto.

Ponte nativo

La guida alle informazioni sul Browser Bridge spiega l'adattatore Node/Python separato, l'origine esatta dell'estensione, le porte proxy/controllo, il token e il trust della CA HTTPS. Utilizza URL di destinazione reali; non è necessaria alcuna voce bridge.invalid o Hosts-file. Le sovrascritture dei cookie e la sincronizzazione delle risposte sono indipendenti. Un biscotto raffermo rotante può essere scambiato per una sonda scanner; disabilita la conservazione automatica delle modifiche quando il jar di Firefox/Chrome deve rimanere autorevole e proteggere esplicitamente i campi di test intenzionali.

Differenze tra Chrome e Firefox

Chrome utilizza Manifest V3 e richiede che il workbench visibile rimanga aperto. L'attuale build di Chrome disabilita esplicitamente le funzionalità di blocco, live-DOM, contenitore e acquisizione in background elencate solo per Firefox. Firefox mantiene le funzionalità della piattaforma supportata. Leggi la nota sulla capacità del prodotto invece di dare per scontato una copertura identica.

Segnalazione di un problema

Apri un questione del sostegno pubblicooppure utilizza il contatto sviluppatore/editore nell'elenco dello store del browser una volta elencata l'estensione. I problemi di GitHub sono pubblici; per inviarne uno è necessario un account GitHub. Include le versioni del browser/estensione, l'azione e un errore oscurato. Non inviare cookie di sessione, credenziali, target privati, chiavi private CA o report sensibili non elaborati. Questo sito Web non contiene un modulo di contatto né raccoglie richieste di supporto.
