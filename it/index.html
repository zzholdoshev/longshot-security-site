Costruito velocemente.

Longshot è un'estensione per Firefox e Chrome che consente di individuare i punti deboli della sicurezza nelle applicazioni Web di tua proprietà o che sei autorizzato a testare. Combina scansione delle sessioni del browser, fuzzing, modelli di vulnerabilità e report ricchi di prove. Il suo Browser Bridge opzionale consente a strumenti come ZAP e curl di inviare le proprie richieste HTTP con cookie del browser configurabili e override di intestazione.
